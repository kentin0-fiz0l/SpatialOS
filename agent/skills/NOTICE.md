# Third-party skills

The `gadget-*` directories and `CATALOG.md` are from Meta's
[muse-gadget-sdk](https://github.com/facebookincubator/muse-gadget-sdk) (`skills/`),
copied on 2026-10-03 and licensed under Apache 2.0 (see `LICENSE-muse-gadget-sdk`).
They are unmodified except where noted in a skill's own header.

Every skill refers to a shared `home_link.md` for networking and safety rules. Meta's
version is not published; ours is `home_link.md` in this directory and describes how
devices are reached through the SpatialOS watchdog instead of Muse Home Link.
